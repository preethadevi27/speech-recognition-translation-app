**Speech Recognition and Real-Time Translation App**



An advanced mobile application designed to break language barriers by providing instant speech recognition, real-time translation, and multilingual communication.

This system enables users to convert speech to text, translate it into the desired language, and listen to the translated output using text-to-speech features.



**Project Overview**



The Speech Recognition and Real-Time Translation App is built to provide seamless communication across diverse languages.

It offers an interactive experience through:



🎤 Speech-to-Text Translation

Users speak through the microphone → the app recognizes speech → instantly translates it into the selected target language.



🗒 Text-to-Speech Translation

Users can type text manually or scan printed text using camera-based OCR, which is then translated and spoken out loud.



🔄 Conversation Mode

Enables real-time, two-way multilingual communication.



⭐ Favorites Section

Frequently used translations can be saved for quick access.



📤 Share Translations

Supports sharing via messaging apps, email, and social media.



📥 Download Translations

Allows saving translated audio or text directly to mobile storage.



**Key Features**



✔ Real-time speech recognition

✔ OCR-based text scanning



✔ Text-to-speech conversion



✔ Two-way conversation mode



✔ Translation history and favorites
